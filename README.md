# 北极星 AI 剪辑 · Polaris AI Edit Motion (Remotion)

基于 Remotion 打造的 30 秒手绘纸感 NLE 自动剪辑过程动效，结合 **OpenChatCut** 工程结构（`AstraArc_Partners_Native_v5.ccproj`），完整呈现「北极星 AI 剪辑」从一键装载素材、智能剔除冗余、空心入网转场、`Ctrl+Z` 瞬时修正、实时电影级调色、AI 音乐卡点到 99.99% 极速导出的全流程。

- **分辨率 / 帧率 / 时长**：`1280 × 720` · `30 FPS` · `30.0s`（900 frames）
- **Composition ID**：`PolarisAIEditMotion`

## 快速开始

```bash
npm install
npm run studio   # 在 Remotion Studio 中实时预览与调试
npm run render   # 渲染成片至 out/polaris_ai_edit_motion.mp4
```

## 9 幕节奏结构

1. **`0.0s – 1.5s` 代码启动**：手绘终端执行 `北极星AI.一键成片("AstraArc_Native_v5.ccproj")`。
2. **`1.5s – 5.2s` 极速装轨（开工!）**：北极星 AI 吉祥物伸出橡胶长臂，将 5 幕实拍/成图素材与 Suno 史诗交响 + 26 轨旁白瞬间铺满时间轴。
3. **`5.2s – 7.8s` 智能删废片（唰! 哐当!）**：自动识别未渲染白模冗余停顿片段，一键切片丢进垃圾桶并无缝吸附时间轴。
4. **`7.8s – 11.2s` 转场空心入网**：切至转场面板，为每个剪辑点精准打入星芒转场节点。
5. **`11.2s – 15.2s` 字幕与瞬时纠错（Ctrl+Z → 已修正 ✓）**：落轨金句字幕，发现错字瞬间按下 `Ctrl+Z` 自动修正并盖章确认。
6. **`15.2s – 19.6s` 电影级实时调色**：推镜至右侧调色面板，拉动对比度、星辉饱和度（趣味爆表回拉）与 IMAX 低频，监视器画面实时同步变化。
7. **`19.6s – 23.6s` AI 音乐卡点**：点击 `▼ AI 卡点`，金色节拍标记沿交响波形级联落点，触发画面卡点脉冲。
8. **`23.6s – 26.8s` 极速渲染导出（99.99% → 叮!）**：点击导出后飙升至 `99.99%`，短暂停顿后 `叮!` 完成交付。
9. **`26.8s – 30.0s` 成片展示与收工便签**：呈现最终品牌片监视器预览与手绘便签「30 秒一键成片，北极星 AI 剪辑 — OpenChatCut 收工 ✨」。
